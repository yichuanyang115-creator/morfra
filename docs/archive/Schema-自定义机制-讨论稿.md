## 术语约定 ✅

| 术语 | 含义 | 出现场景 |
|---|---|---|
| 属性 | 实体级的数据项 | 看板列、详情页属性区 |
| 字段 | Tab 内每条记录的结构 | 任务/产出/验收等 Tab 内部 |
| 实体 | 一条被管理的对象（系统不给它命名，UI 用中性表达） | 看板行、详情面板 |

## 1. 出发点

用户最初需求："看板列表格化"（列可调宽/调序）。追问后发现真实意图更大：整个应用要向"套皮飞书多维表格 / Notion"方向改造——看板列、详情页属性、任务/产出/验收等子 Tab，本质都该是同一套用户可自定义的数据结构在不同地方的渲染。

---

## 2. 系统骨架属性 ✅

系统有且仅有两个骨架属性，不出现在用户可创建的属性类型列表里：

| | Name | Stage |
|---|---|---|
| 唯一/系统自带 | 是 | 是 |
| 可删除 | 不可 | 不可 |
| 可改类型 | 不可 | 不可 |
| 可改显示名 | 可以（如改成"标题"） | 可以 |
| 可新建第二个 | 不可 | 不可 |
| 看板表现 | 固定最左列，可调宽（下限 140px），不参与横向滚动 | 以阶段分组形式存在，不是列 |
| 看板隐藏 | 不可 | 不适用 |
| 详情页属性区隐藏 | 不可（强制显示） | 可以 |
| 值是否必填 | 是（不能为空） | 是（由创建上下文决定：在哪个阶段新建就属于那个阶段） |

### Stage 的特殊规则
- 选项最少 1 个，不允许清空到 0
- 每个选项可标记"终态"（对应归档判定）
- 终态阶段的行为：不显示新建按钮、禁止拖入排序、显示搜索框
- 删除阶段选项：若该阶段下还有实体居住，禁止删除
- 删除阶段选项对历史流转记录：冻结为纯文本快照保留展示
- 颜色：用户可自定义（预设色板 8-12 种，默认按顺序分配）
- 阶段顺序：只在 Schema 设置页调整，看板上不能拖

## 3. 用户可创建的属性类型 ✅

| 类型 | 预制行为 |
|---|---|
| 单选（Single Select） | 选项列表可增删改名，自动配色（色板轮询） |
| 多选（Multi Select） | 选项列表可增删改名，自动配色，一个实体可同时选多个 |
| 数字/百分比 | 范围裁剪 + 单位后缀 |
| 日期 | — |
| 文本 | — |
| 勾选 | — |
| 附件 | file/link |
| 计算属性（系统预置） | 逻辑锁死，名称/是否显示可配；可删、可隐藏、不可新建同类 |

**系统预置计算属性**（出厂自带，不依赖 AI）：
- 停留天数（当前阶段已待多久）
- 总耗时（从创建到现在）

**用户自定义计算属性**：通过 AI 对话创建，随 AI 功能二期交付。引用范围 = 同实体其他属性 + 子 Tab 记录聚合，不跨实体。被引用属性删除时，计算属性报错。

**属性命名唯一性**：同一份 Schema 里两个属性不能同名，新建或改名时重名拦截提示。

**顶部搜索范围**：仍只搜 Name，不扩展到其他文本属性。

**现有属性的改造**：
- 优先级 = 单选实例（默认选项 P0/P1/P2），选项可增删改名，配色自动
- 来源 = 普通单选实例（默认选项 用户反馈/竞品分析/内部想法），选项只能在 Schema 设置页增删改，不再保留"详情页当场输入追加"特例

## 4. 属性依赖与阶段覆盖 ✅

两个独立机制，都对用户自建属性开放：

### 4.1 属性依赖显示
"属性 B 仅当属性 A 取某值时才显示"，纯 show/hide。
- 配置入口：Schema 设置页属性编辑面板里的"显示条件"，单条件
- 看板表现：按行空白（列始终存在，条件不满足的行该格子为空，不是整列消失）
- Tab 内同理：字段依赖某字段值时，条件不满足该记录内不显示

### 4.2 阶段属性覆盖
某个阶段选项声明"在这个阶段下，一批属性被另一批属性替换（占同一列位）"。
- 配置入口：Schema 设置页阶段管理区，每个阶段选项的编辑面板里配"属性覆盖"
- 不是 show/hide，是整批换掉

### 4.3 优先级规则 ✅
**覆盖优先于依赖**。覆盖先决定"这个位置放谁"，依赖只作用于覆盖后实际占位的那个属性自身。原属性的依赖条件在被覆盖的阶段里不生效。

## 5. 属性隐藏：两套独立开关 ✅

属性的"隐藏"拆成两个独立维度：
- 看板隐藏：该属性是否在看板列中显示
- 详情页属性区隐藏：该属性是否在详情面板属性区显示

两者互不影响。配置位置：Schema 设置页属性列表行上的眼睛图标（看板👁 / 详情页👁），即时生效。看板顶部条"字段"面板也能控制看板显隐（联动同一份数据）。

## 6. Tab 模型 ✅

### 6.1 统一模型
> **Tab = 一份字段 Schema + 不限数量的记录列表**

任务/产出/验收/用户自建 Tab 都是同一模型的实例。

### 6.2 Tab 双层质量
- **预制 Tab**（来自模板的任务/产出/验收/活动）：保留手工定制的高质量专用组件渲染。字段结构可改，但卡片布局逻辑固定——这是经过设计验证的 best practice
- **用户自建 Tab**：通用字段渲染器，卡片布局为"字段从上到下排列"的标准形态

Schema 对预制 Tab 需要一个 `renderer` 标识，告诉系统用专用组件而非通用渲染器。

**预制 Tab 字段被修改后的容错规则**：专用组件按"字段存在就渲染、不存在就跳过、多出来的自定义字段追加到卡片末尾用通用渲染"处理。不因字段变动整体退回通用渲染器。

### 6.3 固定特例
- **正文 Tab**：一整块富文本，不接入 Schema 体系，设置页只有"是否显示"开关。正文是实体自身的属性（body），始终存在于数据层，Tab 只控制展示
- **活动 Tab**：固定结构（流转事件 + note + 评论），不接入字段自定义体系。作为预制 Tab 存在（来自模板），空白项目不默认带。**流转记录始终在数据层生成**，不管活动 Tab 是否存在——用户什么时候添加活动 Tab，历史记录都在

### 6.4 Tab 管理
- 新建 Tab：只在 Schema 设置页操作，Tab 栏不放"+"按钮，保持干净
- 删 Tab：级联永久清除该 Tab 下全部记录数据，二次确认

## 7. 操作分层 ✅

| 层级 | 操作 | 位置 |
|---|---|---|
| 视图偏好（可逆，不动 Schema） | 列宽、列序、隐藏属性、冻结范围 | 看板主界面直接操作（拖拽、右键菜单、字段面板） |
| 结构新增（零风险） | 新建属性 | 看板顶部条字段管理面板底部"新建属性"按钮 |
| 结构变更/删除（有风险） | 改类型、改选项、删属性、删 Tab、删阶段选项、新建 Tab | Schema 设置页 |

### 7.1 改属性类型对已有数据的影响 ✅
有损时弹确认告知影响条数（"50 条记录中有 12 条无法转换将被清空"），用户决定是否继续。

转换规则：
| 转换 | 处理 |
|---|---|
| Multi Select → Single Select | 保留第一个值，丢弃其余 |
| Single Select → Multi Select | 安全，单值变一项多值 |
| Select → 文本 | 选项名转纯文本 |
| 文本 → Select | 匹配选项保留，不匹配清空 |
| 任意 → Stage / Stage → 任意 | 禁止（骨架属性不可改类型） |

## 8. 看板表格化 ✅

### 8.1 基本形态
保持现有"阶段分组 + 表格行"形态（不是传统卡片看板）。阶段作为分组行头，实体作为行，属性作为列。

### 8.2 列规则
- Name 列固定最左、可调宽（下限 140px）、不可隐藏、不参与横向滚动
- 其余属性列：可调宽（下限=各自默认宽度）、可调序、可隐藏
- 冻结：从左向右连续扩展，右键"冻结至此列"仅当左侧已全部冻结时出现
- 看板区域内部可横向滚动，行宽度上限解除

### 8.3 阶段分组
- 折叠/展开：保留现有行为
- 阶段顺序：只在 Schema 设置页调整

### 8.4 排序
- 排序分两层：顶栏全局排序 + 每个阶段标题行局部排序
- 优先级层级（高→低）：手动拖拽 > 阶段局部规则 > 全局规则
- 手动拖拽只影响被拖的那个阶段，其他阶段继续跟着各自规则
- 重新激活排序规则（全局或局部）会覆盖手动顺序
- 排序面板可选属性：所有可排序类型（单选、数字、日期、计算属性），文本/勾选/附件排除
- 新建实体排在最上面
- 拖拽排序：只能拖拽实体行最左侧的把手区域

### 8.5 阶段转移 ✅
- 自由拖动，不设前置条件守卫（明确不做"进入某阶段前必须填某些属性"的门禁机制）

### 8.6 筛选 ✅
- 作用范围：仅看板（过滤哪些实体可见）
- 组合逻辑：仅 AND
- 持久化：按项目落盘
- 交互形态：下拉面板（跟排序/字段面板同一模式）
- 条件结构：选属性 → 选运算符 → 选值，底部"+ 添加条件"
- 可筛选范围：所有属性类型，无排除
- 运算符按类型区分：单选=≠为空不为空 / 多选包含不包含 / 数字=≠><≥≤ / 日期=之前之后 / 文本包含不包含 / 勾选=true=false
- 视觉提示：筛选激活时按钮高亮 + 旁边 tag 显示条件数，tag 上 × 清除

### 8.7 实体删除 ✅
- 永久删除，任意阶段可执行
- 入口：看板行右键菜单 + 详情面板头部按钮
- 二次确认，级联删除所有子记录/流转/评论
- 不可 Undo（靠确认弹窗兜底）

## 9. 详情面板 ✅

### 9.1 属性区
- 动态渲染 Schema 中详情页可见的属性列表
- 排序：独立于看板列序，在 Schema 设置页配置
- 打开方式：点击看板行展开
- 关闭方式：详情面板右上角关闭按钮（×）
- 全屏：详情面板右上角已有

### 9.2 新建实体
- inline 输入 Name 创建（在阶段分组内点新建按钮）
- 有内容时：回车 或 失焦 = 创建成功
- 无内容时：回车 或 失焦 = 取消，输入框消失
- Stage 由创建上下文决定，其余属性默认空

## 10. Undo 机制 ✅

### 可 Undo
- 属性值修改
- Tab 内记录增删改
- 手动排序
- 拖拽换阶段

### 不可 Undo（靠二次确认兜底）
- 结构性操作：删属性、删 Tab、改属性类型、删阶段选项
- 永久删除实体

### 规格
- 多步 Undo（栈深 50）
- 关掉应用清空
- 不做 Redo
- UI 反馈：底部 toast "已撤销：[操作摘要]"，2-3 秒消失

## 11. UI 布局规划 ✅

### 11.1 顶栏布局
```
[搜索框]          [筛选] [排序] [字段] ··· [⚙ Schema 设置]
```
- 去掉原有的详情面板收起/展开按钮（详情面板由点击看板行展开、右上角×关闭）
- 左侧搜索，右侧一组视图控制按钮，最右齿轮

### 11.2 字段管理面板（顶部条"字段"按钮）
- 属性列表 + 眼睛图标控制看板显隐
- 可拖拽排序（调整看板列序）
- 底部"新建属性"按钮

### 11.3 右键表头菜单
- 隐藏此属性
- 冻结至此列（仅当左侧已全部冻结时出现）
- 编辑此属性（跳转 Schema 设置页对应位置）

### 11.4 Schema 设置页
- 入口：顶栏最右齿轮 + 右键表头"编辑此属性"
- 布局：左侧竖向导航（阶段 / 属性 / 各 Tab 名），右侧编辑区
- 顶部右侧"保存为模板"按钮
- 属性管理区：每个属性行显示两个眼睛图标（看板/详情页隐藏开关），点击属性展开编辑面板（类型、显示名、显示条件）
- 阶段管理区：每个阶段选项可编辑名称、颜色、终态标记、属性覆盖规则
- Tab 管理区：Tab 列表（顺序、显隐）、每个 Tab 内部的字段配置、新建 Tab 入口

## 12. 新建项目与模板 ✅

### 12.1 空白项目
- 只有 Name + Stage（一个名为"默认"的阶段选项），无其他属性
- 进来即可用，之后去 Schema 设置页加属性和阶段

### 12.2 模板
- 新建项目弹窗：输入项目名 + 下方模板选择区。不选 = 空白，选了 = 套模板。无"空白"显式选项
- 模板只保存 Schema 结构，不保存数据
- 内置 reqflow 模板（7 阶段 + 现有属性 + 任务/产出/验收/正文/活动 Tab），可删可改
- 用户自定义模板：在项目 Schema 设置页点"保存为模板"创建（唯一创建路径）
- 模板管理（列表、改名、删除）：只在新建项目弹窗里操作
- 存储位置：应用级共享目录，不随来源项目删除而丢失

## 14. AI 对话生成 Schema ⛔ 独立立项，不进本次改造

第 6 节全部内容（AI 对话生成、模型接入、Key 存储、预览确认、多轮逆问、用户自定义计算属性）独立立项，不进这次 Schema 改造的 DEV-PLAN。

**理由**：
- 前置依赖：手动 Schema CRUD 必须先完整稳定
- 变更风险：核心 Schema 模型调整时 AI prompt/结构映射要全部重做
- 范围控制：Schema 引擎本身已是大工程量

**保留的设计决策**（供二期参考）：
- 技术定性：普通结构化生成，不是 Agent
- 模型接入：OpenAI 兼容接口，用户自填 Key + Endpoint
- Key 存储：系统密钥串/加密存储
- 生成后先预览再确认
- 对话框模式切换
- 多轮逆问 + 增量改动
- 不做调用频次限制

## 16. closureType 消解 ✅

系统不再需要 `closureType` 专属字段。"完成/废弃"区分靠：
- 用户自建单选属性 + 属性依赖（仅终态阶段显示）+ 模板预置

## 17. Schema 归属 ✅

每个项目独立一套 Schema（属性定义、Tab 列表、阶段选项），项目间不互通。落盘到项目目录下。视图偏好（列宽/列序/隐藏/冻结/筛选/排序）同样按项目持久化。

## 18. 批量操作 ⛔ 首版不做

首版不支持多选实体批量操作。后续按需加。
